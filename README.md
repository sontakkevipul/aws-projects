## 📂 Projects

### 01. Automated Data Export Pipeline

An automated AWS data export solution that retrieves data from Amazon RDS,
generates a CSV file, stores it in Amazon S3, and sends the exported file
through Amazon SES.

**AWS Services:**

- Amazon EventBridge
- AWS Lambda
- Amazon RDS
- Amazon S3
- Amazon SES
- AWS IAM
- AWS Secrets Manager
- Amazon CloudWatch
- Amazon SNS

**Key Concepts:**

- Event-driven automation
- Lambda-based data processing
- Secure database access
- CSV generation
- S3 storage
- Email notification
- CloudWatch monitoring
- Failure notifications
